## Community Onboarding
Discord officially recommends Community Onboarding so people choose channels and roles instead of landing in chaos.

Set these as Default Channels:
- `#welcome`
- `#rules`
- `#announcements`
- `#general`
- `#daily-check-in`
- `#gym-wins`
- `#beta-access`

### Required onboarding question 1
Question:
`What are you here for?`

Answers:
- `Get beta access`
- `Find better training`
- `Track progress`
- `Meet gym people`
- `Follow the build`

### Required onboarding question 2
Question:
`What kind of lifter are you?`

Answers:
- `Beginner`
- `Bodybuilding`
- `Powerlifting`
- `Athletic performance`
- `Just getting back into it`

### Optional onboarding question 3
Question:
`What do you want to see more of?`

Answers:
- `Build updates`
- `AI coach tips`
- `Workout programming`
- `Progress posts`
- `Creator opportunities`

## Permissions Rules
- Only staff can post in `#announcements`, `#roadmap`, and `#rules`.
- Everyone can chat in `#general`, `#daily-check-in`, `#gym-wins`, and `#questions`.
- `#bug-reports` should use threads only so feedback stays clean.
- `#physiques-and-progress` should be opt-in and 18+ only if you want zero drama.

## Ready-To-Paste Copy
### Welcome message
`Welcome to REPMAX. This is where we build the app, test new features, share progress, and help each other stay locked in. Pick your roles, tell us your goal, and jump into beta access if you want to test features early.`

### Rules
1. Respect people.
2. No spam.
3. No fake natty drama or harassment.
4. Keep bug reports clear and useful.
5. If you post progress pics, keep it tasteful.
6. Staff decisions are final when safety is involved.

### First announcement
`REPMAX is live in beta. We are building an AI training app that adapts your programming, keeps your progress tight, and makes training more social. If you want early access, head to #beta-access and introduce yourself in #introductions.`

### Daily check-in prompt
`What did you train today, and what almost made you skip it?`

### Bug report template
`Device:`
`Page:`
`What happened:`
`What you expected:`
`Screenshot or screen recording:`
`Can you reproduce it: yes/no`

## Weekly Rhythm
- Monday: feature poll
- Tuesday: progress thread
- Wednesday: bug sweep
- Thursday: build update
- Friday: win of the week
- Saturday: voice hangout
- Sunday: next-week roadmap

## Best Setup Order
1. Create the server.
2. Enable Community mode.
3. Turn on Community Onboarding.
4. Add the roles above.
5. Create the channels above.
6. Publish onboarding.
7. Post the first announcement.
8. Invite your first 20 to 50 users personally.
